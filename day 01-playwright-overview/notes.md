# Playwright Overview

## What is Playwright?

Playwright is an open-source test automation framework 
developed by Microsoft in 2020.

It allows developers and testers to automate browser 
interactions just like a real user — clicking buttons, 
filling forms, navigating pages, and verifying results.

Playwright supports three major browsers:
- Chromium (Google Chrome)
- Firefox
- WebKit (Apple Safari)

All of this works with a single API and single codebase.

---

## Features

- **Multi-browser** — Run tests on Chrome, Firefox 
  and Safari with same code
- **Auto-wait** — Automatically waits for elements 
  before performing actions
- **Fast Execution** — Runs tests in parallel, 
  saving time
- **Screenshots** — Captures screenshots on test failure
- **Video Recording** — Records full test execution
- **Mobile Emulation** — Simulates mobile devices
- **Network Control** — Intercept and modify API calls
- **Multiple Languages** — JavaScript, TypeScript, 
  Python, Java, C#

---

## Playwright vs Selenium

| | Playwright | Selenium |
|--|------------|---------|
| Created By | Microsoft (2020) | ThoughtWorks (2004) |
| Speed | Fast | Slow |
| Auto-wait | Yes | No |
| Setup | Easy | Complex |
| Safari Support | Yes | Limited |
| Mobile Emulation | Built-in | Separate Tool |

### In Short:
Selenium is older and complex.
Playwright is modern, fast and easy to use.
